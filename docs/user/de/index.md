# Edbert Bedienungsanleitung

Edbert beschreibt deinen Stromtarif einmal und berechnet daraus den Preis jeder Viertelstunde. Diese Anleitung behandelt den **Tarif-Editor** (die Browserseite), die Ausgabe über MQTT und die Kommandozeile. Die englischen Seiten sind maßgeblich, diese Seiten sind eine Übersetzung.

**Status:** Entwurf. Der Editor und die MQTT-Ausgabe funktionieren; eine native Home-Assistant-Integration gibt es noch nicht.

Kapitel:

1. [Erste Schritte](getting-started.md): Installation, Editor starten, Sprache
2. [Der Tarif-Editor](editor.md): die vier Schritte, Vorschau, Speichern
3. [Einen Tarif prüfen](checking.md): Preisverlauf, Preis zu einem Zeitpunkt, Rechnungsprüfung, Hinweise
4. [Import und Kopieren](import.md): Katalogtarif kopieren, JSON importieren
5. [Kommandozeile](cli.md): Preis eines Zeitabschnitts, Preisreihe, Schema
6. [Über MQTT veröffentlichen](publishing.md): Topics, Börsenpreise, optionale Prognose
